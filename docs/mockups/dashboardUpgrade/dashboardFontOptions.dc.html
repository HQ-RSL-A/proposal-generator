Which font for the dashboard?

Each option below renders the same dashboard cluster — a heading, the MRR hero, and a metric card — so you compare letterforms and figures directly. You're currently running three fonts (Satoshi · Space Grotesk · Inter).

My recommendation

Go two fonts — Satoshi for display, Inter for everything else.

It keeps the brand character you already have in headings, but retires Space Grotesk — the uppercase tags move to Inter, so the UI calms down and reads as one voice. Inter is the gold standard for tabular figures, which this dashboard is full of. If you'd rather have one engineered family, Geist + Geist Mono (option 2) is the strong alternative.
